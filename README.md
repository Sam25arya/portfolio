# Arya Sawant Portfolio

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Files
- `index.html` — page structure
- `style.css` — responsive dark/neon design
- `script.js` — navigation, animations, filters, theme and AI assistant demo

## Before publishing
Replace:
- GitHub / LinkedIn `#` links
- `your-email@example.com`
- Resume links
- Project descriptions and project images
- Certificate names
- Education details

## AI model
The AI Assistant currently has a local demo response system. For a real AI model, connect the chat form to a secure backend API. Do not put an API key directly in `script.js`.
